# SMTP 配置部署交接说明

## 环境变量

| 变量名 | 必需 | 默认值 | 说明 |
|--------|------|--------|------|
| `SMTP_HOST` | ✅ | - | SMTP 服务器主机名（如 `smtp.gmail.com`） |
| `SMTP_PORT` | ❌ | `587` | SMTP 端口（通常 587 用于 STARTTLS，465 用于 SSL） |
| `SMTP_USER` | ❌ | - | SMTP 认证用户名（如需要认证） |
| `SMTP_PASS` | ❌ | - | SMTP 认证密码（如需要认证） |
| `SMTP_FROM` | ✅ | - | 发件人邮箱地址（如 `noreply@l2cl.link`） |
| `SMTP_SECURE` | ❌ | `false` | 是否使用 SSL（`true` 表示 465 端口） |

## 配置行为

系统会自动检测 `SMTP_HOST` 和 `SMTP_FROM` 是否已配置：

- **已配置**：启用邮箱验证、密码重置、邮箱变更功能
- **全部未配置**：禁用邮箱注册、密码重置和邮箱变更，仅保留 GitHub/爱发电 OAuth 登录
- **部分配置或值无效**：应用启动失败并指出错误变量，避免开放无法完成验证的账号流程
- `SMTP_USER` 与 `SMTP_PASS` 必须同时设置或同时省略
- `SMTP_PORT` 必须是 `1..65535` 的整数；`SMTP_SECURE` 只能为 `true` 或 `false`

敏感账户操作的会话新鲜度由 `FRESH_SESSION_MAX_AGE_MINUTES` 控制，默认 `15` 分钟。

## 验证配置

部署前使用供应商提供的测试收件箱完成一次注册验证和密码重置。发送失败会直接让认证请求失败；系统不会把失败投递记录成“已发送”。日志不会输出 SMTP 密码、验证令牌或完整验证链接。

## 生产环境注意事项

1. **不要**将 SMTP 密码硬编码在代码中
2. **使用** Vercel 环境变量存储敏感信息
3. **测试**邮件发送功能后再部署到生产环境
4. **监控**邮件发送失败率，确保服务可用性

## 回滚方案

如果邮件服务出现问题，可以临时禁用：

1. 删除或清空 `SMTP_HOST` 和 `SMTP_FROM` 环境变量
2. 重启应用
3. 用户仍可通过 GitHub/爱发电 OAuth 登录
